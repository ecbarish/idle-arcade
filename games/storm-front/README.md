# Storm Front

AC1: an original Saltmarsh harbour cabinet. Marching clouds descend, speed up as their formation thins, and fire rain at a movable lighthouse lamp. Four sea walls erode under rain and your own shots. A passing gull gives 150 bonus points. Each player has three lights; two-player mode gives each player a complete turn and an independent score.

Arrows or A/D move, Space fires, P pauses. Touch supports simultaneous movement and firing. A standard USB gamepad uses the left stick or D-pad to move, A/right trigger to fire, and Start to pause. Use the D-pad to choose a menu button and A or Start to select it. Start pauses and resumes. On-screen buttons work too. The title screen runs a demonstration; it never saves scores. Finished runs enter three initials on a five-entry local board. Runs themselves are not saved.

Uses shared arcade sound, text size and reduced-motion settings. Scanlines are off by default and hidden with reduced motion. Art and tune are original code; no third-party assets. Does not read or change other games' saves.

Checks: `node tools/storm-model-checks.cjs` and `node tools/run-all-checks.cjs storm-front`. Browser checks cover real controls, turns, score saving and phone/desktop layouts. Screenshots are captured by the Storm Front review workflow.
